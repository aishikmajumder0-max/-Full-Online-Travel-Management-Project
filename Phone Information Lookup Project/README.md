# Online Phone Information Lookup Project

A safe Python desktop project for basic phone-number format and country-code lookup.

## Important Privacy/Safety
This project does NOT:
- Track live GPS location
- Access device location
- Reveal a person's private identity
- Access call logs, messages, contacts or accounts

## Features
- Phone number format validation
- Country/country-code lookup for a small built-in prefix list
- International/local classification
- Local SQLite search history
- CSV export
- Clear history

## Run
```bash
python app.py
```

No external package is required.
