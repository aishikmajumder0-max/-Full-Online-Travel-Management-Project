# Phone Information Lookup System - Project Report

## 1. Introduction
This project demonstrates a privacy-preserving phone number information lookup application using Python and Tkinter.

## 2. Objective
To validate a phone number and identify basic country information from its country calling code without tracking a person's location.

## 3. Technologies
- Python 3
- Tkinter
- SQLite
- Regular Expressions
- CSV

## 4. Features
1. Phone number input
2. Format validation
3. Country calling-code detection
4. International/local classification
5. Search history
6. CSV export
7. History deletion

## 5. Privacy
The application does not use GPS, cellular triangulation, spyware, contact access, call records, or private identity databases.

## 6. Future Improvements
A legitimate production version could use an authorized phone-number metadata API for broader country/carrier information, subject to its terms and privacy requirements.
